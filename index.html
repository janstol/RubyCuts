RubyCuts

Write real Ruby, run it from Shortcuts. The full Ruby interpreter and standard library on your iPhone, iPad and Mac.

View on GitHub Get support

iOS 26, iPadOS 26 and macOS 26 or later. Coming soon to the App Store.

What it does

Real Ruby, not a subset

CRuby, the standard Ruby interpreter, with its standard library: json, csv, yaml, net/http over HTTPS and more.

Two Shortcuts actions

Run Ruby Script picks a saved script, Run Inline Ruby takes code typed right into your shortcut.

Talks like a CLI

Inputs arrive in ARGV, STDIN and ENV. Whatever you print goes to the next action. Errors stop the shortcut with Ruby's message.

An editor made for it

Syntax highlighting, a console with output, errors and timing, a Stop button, and sample scripts to start from.

Synced with iCloud Drive

Scripts are plain .rb files in iCloud Drive, so they follow you between devices and open in any editor.

Talks to the device

The built-in Device module lets scripts read and write the clipboard and post notifications.

A taste

# Shortcuts passes text in on STDIN, the output goes to the next action.
require "json"

lines = STDIN.read.lines.map(&:strip).reject(&:empty?)
puts JSON.generate(count: lines.size, longest: lines.max_by(&:length))
